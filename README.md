## Overview
Travelers have a budget when going to other countries.
Knowing how much their money will last and what to pack is important.
The weather and currency site helps users get up-to-date exchange rates from any currency to any other type. 
The site, along with the currency result from the country requested, also provides the current weather. 

## Features
* Currency conversion as desired
* Weather forecast of the destination

## Technologies Used
* Front-end: HTML/CSS, JavaScript
* Styling: CSS, Bootstrap
* External: APIs

## Usage 
Users type the desired country they need the currency exchange from, and find out how much foreign currency they need and know the weather forecast for the country they searched. 

## Summary
The Currency Convenience application will help the users get a better understanding of their destination by having access to information such as the currency they will be using and the weather.
